# Odin Recipes

A simple HTML website showcasing a few recipes. This project is part of The Odin Project Foundations course.

## Skills Demonstrated
- Basic HTML structure
- Linking multiple pages together
- Adding images with proper paths
- Using Git for version control

## Reflection
This was my first project in TOP. I practiced setting up a repo, committing changes, and pushing to GitHub. The project helped me understand how to structure a multi-page site and reinforced the importance of clear commit messages.
